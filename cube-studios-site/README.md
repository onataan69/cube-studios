# Cube Studios — Site Minecraft

Site estático completo para divulgação do servidor Minecraft Cube Studios.

## Estrutura

- `index.html` — página principal
- `style.css` — visual, responsividade e animações
- `script.js` — menu mobile, copiar IP, FAQ e interações

## Antes de publicar

Troque no `index.html`:

1. `play.cubestudios.com` pelo IP real do servidor.
2. O link do Discord no botão `ENTRAR NO DISCORD`.
3. Os nomes/preços dos ranks da loja.
4. Os números de jogadores/ranking.
5. A versão do Minecraft.

## Como testar

Abra `index.html` no navegador.

Para publicar, você pode usar GitHub Pages, Cloudflare Pages, Netlify ou Vercel.
